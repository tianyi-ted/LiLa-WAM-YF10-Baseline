# 对话上下文归档

此目录用于保存 LiLa-WAM 研究相关对话的上下文摘要，方便在新对话中恢复项目背景。

请生成一份用于新对话接续的上下文摘要，包含研究目标、已确定方案、代码改动及路径、数据与训练配置、实验结果、未解决问题和下一步。明确区分已完成与计划中的工作。

## 文件

- [VLA研究路径真机LiLa_上下文摘要.md](VLA研究路径真机LiLa_上下文摘要.md)：EDULITE A3 单臂 VLA 真机研究的目标、数据定义、配置、已知问题和后续计划。

## 使用方式

开始新对话时，将摘要文件内容粘贴给助手，并说明当前代码以仓库实际文件为准。摘要记录研究背景，不替代对当前代码和配置的检查。
